# MedPharm-ERP-Deploy-AWS
Deploying the medpharm-erp application using AWS services, without adding external database 

## Project Overview
Deploy a microservices-based MedPharm ERP application
using AWS cloud infrastructure.

## Architecture
- Amazon VPC
- Amazon EC2
- MongoDB Community Server
- Amazon S3
- Amazon CloudFront
- Application Load Balancer
- Security Groups
- CloudWatch

## Microservices
1. User Service
2. Product Service
3. Order Service

## Database
MongoDB:
- user_db
- product_db
- order_db
